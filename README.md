# Tourisme à Vitesse Grand C

## Comment Edité un Plateau ?

### Lancer l'Application
Allez dans le répertoire /lancerEdition et executer LancerCreation.bat sur Windows ou LancerCreation.sh sur Linux.<br>
Vous pouvez ouvrir un plateau déjà existant ou en créer un nouveau.

#### Comment modifier le placement des Planètes ?
Selectionner vôtre type de plateau souhaité grâce aux contrôles sur la gauche de l'écran.<br>
Vous pouvez placer la planète de vôtre choix sur le plateau en faisant un clique gauche sur la case souhaité.<br>
Vous pouvez supprimer une planète placé sur le plateau en faisant un clique droit dessus.<br>
